# Contributor Covenant Code of Conduct

As contributors and maintainers, we pledge to make participation in this project a harassment-free experience for everyone.

Standards:
- Be respectful and kind in communication.
- Be considerate: technical constraints and different backgrounds exist.
- Report unacceptable behavior to the maintainers.

For full text and reporting instructions, the project follows the Contributor Covenant (v2.1). If you need to report a violation, contact the maintainer at: jtatopenn@libero.it
